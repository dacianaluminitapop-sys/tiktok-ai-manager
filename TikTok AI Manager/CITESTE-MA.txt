TIKTOK AI MANAGER — PRIMUL PROTOTIP

CUM ÎL DESCHIZI PE WINDOWS
1. Descarcă și extrage arhiva ZIP într-un folder, de exemplu pe Desktop.
2. Deschide Visual Studio Code.
3. Alege File > Open Folder și selectează folderul tiktok-ai-manager.
4. În lista din stânga, dă dublu-click pe index.html.
5. Pentru testare simplă, poți da dublu-click pe index.html din File Explorer și se va deschide în browser.

CE FUNCȚIONEAZĂ
- Navigare între secțiuni.
- Adăugare companii (datele se păstrează în browserul acestui calculator).
- Generator demonstrativ de texte și idei.
- Calendar demonstrativ.

LIMITĂRI IMPORTANTE
Acesta este doar un prototip local. Nu are autentificare reală, bază de date online,
separarea securizată a clienților, conexiune la un model AI sau publicare TikTok.
Nu introduce date sensibile sau parole reale. Următorul pas va fi configurarea
unei baze de date și a autentificării pentru administrator și clienți.
